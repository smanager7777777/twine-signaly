## Что это
Пакет приложения `.sgpack` (zip: `game.json` + `media/…`, формат — `signaly-app`, `src/common/logic.js`) живёт в истории Twine. Окно **«Приложение»** (вкладка «История», кнопка с телефоном) загружает пакет в историю и собирает его обратно. Старый редактор приложения остаётся для мелких правок (П-61 Т2-10): собрать пакет → поправить в редакторе → загрузить обратно (окно покажет, что поменялось, и спросит — П-61 Т2-11).

## Где что лежит
| Что в пакете | Где в истории |
|---|---|
| Общие настройки (название, версия, мастерский код, код настроек, звуки, палитра, клавиатура, первый вход, камера-улика, тексты, связь, голос и всё прочее верхнего уровня) | пассаж **«Приложение»** с тегом `app-settings`: строка `<<app-general>>{…}<</app-general>>` |
| Главы и стили, приборы, уведомления, аварии, сбои, правила, голосования | тот же пассаж, по строке на запись: `<<app-chapter>>`, `<<app-device>>`, `<<app-notice>>`, `<<app-alarm>>`, `<<app-glitch>>`, `<<app-rule>>`, `<<app-vote>>` (внутри — JSON записи как в `game.json`) |
| Блоки данных | пассажи с тегом **`app-block`** (синий на карте): название пассажа — «Папка/Подпапка/Блок»; первая строка `<<app-block "id" who "1, 3" chapter 2 start share garble 2>>`; дальше — текст блока |
| Картинка и звук в блоке | строки `<<app-img "media/app/план.png" "подпись">>`, `<<app-audio "media/app/запись.mp3" "название">>`; файлы — в папке игры `media/app/` |
| Персонажи (аккаунты) | сотрудники пассажа **«Коды»**: `<<sg-person "1" pin "417" var "$progress1" phone '{"id":"aA","name":"…","login":"111111",…}'>>` — номер сотрудника = «Номер на терминале» (П-61 Т2-7), сотрудник терминала и персонаж — одна запись (П-59 А3) |
| Коды телефона | коды пассажа «Коды»: `<<sg-entry "4242" "Подпись" where phone>>`<br>`<<sg-phone>>{"id":"k1","answer":"…","actions":[…]}`<br>`<</sg-entry>>` |
| Код «оба» (П-59 А4) | `where both`: до `<<sg-phone>>` — действия и ответ терминала, в `<<sg-phone>>` — свой ответ и действия телефона |
| Файлы пакета (`media/…`) | папка игры `media/app/` — все файлы оттуда попадают в пакет (как вкладка «Медиа» редактора) |

## Правила записи
- **JSON одной строкой.** В строках JSON знаки `< > [ ]` записаны как `< > [ ]`, между скобками массивов — пробел: так SugarCube не примет их за команды, а карта Twine — за ссылки `[[…]]`.
- **JSON в слове `phone '…'`** — в апострофах, экранируются только `\` и `'` (`jsonArg` в `signaly-codes.ts`): читается глазами.
- **Персонаж в блоке — номером** (`who "1, 3"`), в JSON (коды, правила, приборы…) — id аккаунта (`"aA"`); связь — сотрудник с `phone` (в JSON — `id`). Персонажам без номера при загрузке даются свободные номера (окно сообщает «Медик Тест → 2»).
- **Без значения по умолчанию.** В первой строке блока не пишутся глава 1, «сразу» = нет и т. п.; при сборке подставляются (как `SG.normalize`). У кода «только телефон» подпись `sg-entry` = комментарий кода.
- **Текст блока.** Строка `<<app-text>>` начинает новый текст, если текст пустой, два текста подряд или у текста есть свои поля; строка текста, похожая на команду блока, пишется с лишней `\` впереди. Свои поля картинки, звука, текста и блока — словом `more '{…}'`.
- **Повтор названия блока** (или занято экраном терминала) — к названию пассажа ` (2)`, а настоящее название и папка — словами `title "…" folder "…"`.

## Загрузка пакета в историю (`gameToStory`)
- Персонаж ищется по id в `phone`, затем по номеру (`num`) среди сотрудников без телефона; не нашёлся — новый сотрудник (личный код пустой). Персонаж ушёл из пакета: сотрудник только для телефона (без личного кода и переменной) убирается, сотрудник терминала остаётся без `phone`.
- Код ищется по id в `<<sg-phone>>`; первый раз — тот же код на терминале (единственный в пакете с таким кодом) становится кодом «оба»; иначе — новый код `where phone` в конце таблицы. Код телефона поменялся у кода «оба» — терминальная часть остаётся, телефонная уходит отдельным кодом. Код ушёл из пакета: «только телефон» — убирается, «оба» — становится кодом терминала.
- Блок ищется по id в первой строке: переименовывается, правится или создаётся; блоков, которых нет в пакете, — пассажи убираются. Файлы пакета пишутся в `media/app/`; файлы, которых нет в пакете, из папки не удаляются.
- Окно заодно ставит движок (29, с сессии 33 — 30) и цвета тегов (`app-block` — синий, `app-settings` — розовый).

## Сборка пакета (`storyToGame`)
Окно «Приложение» → «Собрать пакет»: версия +1 (как «Сохранить» редактора), файл `<название>-v<версия>.sgpack` в папке игры (в веб-версии — скачивание). Нет файла картинки или звука в папке игры — строка «Нет файлов…». Сломанный JSON — строка «Не читается» (пакет всё равно собирается без этой записи).

## Терминал (движок 29)
- `<<sg-entry … where phone>>` терминал не знает («Неверный код»); `where both` — работает часть терминала, `<<sg-phone>>` пропускается.
- `<<sg-person … phone '…'>>` — терминал читает только номер, `pin`, `var`.
- В окне «Коды» коды телефона отмечены «📱 телефон» / «📱 и телефон», персонажи — «📱 персонаж приложения»; повторы и пустые коды «только телефон» не ошибка (приборы, голос), пустой личный код у персонажа — тоже.

## «Телефонам: …» и данные приложения
Если в истории есть данные приложения: «Сбой» и «Снять сбой» — выбор из сбоев приложения; у «Открыть блоки» и «Событие» в подсказке — названия блоков и событий правил. «Проверить историю» показывает сбои и блоки, которых нет в приложении (раздел «Телефонам: нет в приложении»).

## Формы (сессия 33, этап Т3)
Хранение то же — формы пишут те же строки, JSON остаётся (ответ Т3-3 А).
- **«Блок приложения»** — кнопка над текстом пассажа: первая строка `<<app-block "b…">>` с новым номером и тег `app-block`; есть — открывает форму. Форма правит только первую строку (кому — номера, с главы, `start`, `share`, `garble`; `title`, `folder`, `more` — как были) и строки `<<app-img>>` / `<<app-audio>>` (файл из `media/app/`, подпись; новая строка — в конец текста). Щелчок по первой строке или по строке картинки открывает форму. «Это не блок приложения» — строка и тег убираются, текст остаётся. Код — `signaly-app-model.ts` (`readBlockHead`, `writeBlockHead`, `blockMedia`, `setBlockMedia`, `addBlockMedia`), форма — `passage-edit/signaly-app-block-form.tsx`.
- **«Коды» → код:** «Где срабатывает код» (`where`: пусто / `phone` / `both`); у «оба» — вкладки «На терминале» и «На телефоне» (Т3-4 А), у «только телефон» — только форма телефона. Форма телефона (`signaly-codes/signaly-phone-code-form.tsx`) правит JSON `<<sg-phone>>`: пишутся только изменённые поля (`{...было, ...правка}`), значения по умолчанию показываются, но не дописываются. «На терминале» из телефона — телефонная часть удаляется (с подтверждением).
- **«Коды» → «Сотрудники»:** «Персонаж приложения на телефоне» (Т3-5 А) — JSON в слове `phone '…'` (`signaly-phone-person-form.tsx`): имя, профессия, код входа, функции (`modules`, `modChapter`, `modState`), голос (`voiceMode` и функция `voice` вместе), цвет по главам (`colors[глава] = {def, choose, any, pin}`, пустое — убирается). Новый — как «+ Добавить» редактора приложения. Профиль (`items`) не правится (сохраняется как был).
- **Окно «Приложение»** (`signaly-app-window.tsx`, вкладки — `signaly-app-tabs.tsx`): держит у себя общие настройки (как `readSettings`) и таблицу «Коды»; «Сохранить» пишет пассаж «Приложение» (`writeSettings`) и, если правились, «Коды» (`writeCodes`). Пока есть несохранённое, «Загрузить» и «Собрать» недоступны. История поменялась не формами (загрузка пакета) — формы берут новое. Вкладка «Приборы» показывает коды приборов (`app` в части телефона) и добавляет коды «только телефон»; «Голос» правит режим микрофона персонажей и поля фраз прямо в таблице.
- **Списки для выбора** (главы, персонажи по номеру, блоки, уведомления, аварии, сбои, приборы, голосования, палитра) — `appRefs` (`signaly-app-model.ts`), в формах — через `AppRefsContext`; действия телефона — `AppActions` (`signaly-app-fields.tsx`, типы как `ACTIONS` приложения; «Кому» — тому, кто ввёл код / всем / выбранным).
- **Предпросмотр телефона** (Т3-2 А, `signaly-app-preview.tsx`): iframe `signaly-app/player.html#preview` с `name="sg-preview"` — плеер приложения (MIT, копия из `signaly-app` build-38 скриптом `signaly/tools/sync-app-player.py`). Плеер шлёт `sg-preview-ready`, окно — `{type: 'sg-pack', data, account, chapter, unlockAll}`; пакет собирается из того, что в окне (`passagesWith` + `storyToGame` + файлы `media/app/`). Сети нет, плеер ничего не сохраняет.
- Проверки: `src/util/signaly/__tests__/signaly-app-model.test.ts`, `signaly/tests/electron-app-forms.mjs`.

## Формы, сессия 34 (окончание Т3, решения 151–152)
- **Вкладка «Блоки»** (`signaly-app-blocks.tsx`; модель — `blockEntries`, `blockTree`, `renameFolder`, `newBlockIn` в `signaly-app-model.ts`): дерево папок из названий пассажей `app-block` (или слова `folder`), счётчик — блоки с подпапками. Правки — сразу в историю: «Переименовать папку» (пассажи — через временные имена `<имя> ~<id>`; занятое имя — « (2)» и слова `title`/`folder`; блок со словом `folder` — меняется слово), «+ Блок в эту папку» (в названии можно «/» — подпапка; первая строка с новым номером, тег `app-block`). Щелчок по блоку — окно закрывается (с вопросом, если не сохранено), открывается пассаж.
- **Вкладка «QR»** (`signaly-app-media-tabs.tsx`, `signaly-app-qr.ts`): `qrList` — коды «Кодов» (терминал и телефон), коды приборов (`app` в части телефона), коды входа, главы, мастерский и настроек; `qrMatrix` — `qrcode-generator` (MIT); рисунок — как `qrCanvas` редактора приложения. Запись — `signalyWriteOutput(folder, 'QR/<имя>.jpg')` (в главном процессе разрешены только `QR/*.jpg` и `media/audio/sstv/*.wav`); в веб-версии — скачивание (несколько — zip, `fflate`).
- **Вкладка «SSTV»**: картинка (`media/app/`, `media/img/` или файл с компьютера) → кадр режима (заполнить / вписать / растянуть) → `encodeSstv` (декодер-кодировщик движка, `signaly-sstv.ts`) → WAV (`encodeWav`); метка перед картинкой и «Код звуком» — `signaly-modem.ts` (перенос `modem.js` приложения, MIT): `encodeModem`, `decodeModem`. Самопроверка — `decodeSstv` и `decodeModem` на чистом звуке. Запись — `media/audio/sstv/` («Музыка») или `media/app/` (`signalyWriteAppFile`).
- **Профиль персонажа** (`ProfileItems` в `signaly-phone-person-form.tsx`): `items` аккаунта — `{type:'text', text}`, `{type:'image', file, caption}`, `{type:'audio', file, title}`; `file` — имя в `media/app/`; файлы — `useAppFiles`.
- **Картинка у курсора**: `addBlockMedia(text, item, курсор)` — курсор в начале строки — перед ней, иначе — после; не выше первой строки блока; без курсора — в конец. Курсор отдаёт панель (`cursor` → `editor.getDoc().getCursor()`).
- **Проверка истории** (`signaly-app-check.ts`): `appProblems` — перенос `SG.problems` приложения (повторы кодов, вход, главы, коды на удалённые блоки и приборы, закрытые блоки и приборы, файлы профиля и блоков); `storyAppProblems` даёт пассаж, где поправить. В `checkStory` — вид `app` с `level` (`error`/`warn`), файлы — `signalyListAppFiles`.
- Проверки: `signaly-session34.test.ts` (11; ожидаемые проблемы `test-pack` и `test-net-pack` — `fixtures/*.problems.json`, их дал `SG.problems` приложения), `signaly/tests/electron-app-t3b.mjs` (19).

## Сессия 35 (этап Т4, решения 153–154; приложение — `app/05` П-65)
- **Общие с телефонами переменные** (Т4-3 А): окно «Переменные» → «Общая с телефонами» — в разделе StoryInit строка `<<sg-shared "power" …>> /* общие с телефонами */`. В пакете — `shared: [{name, label, value}]` (начальное значение и подпись — из StoryInit). Значение хранит центр сети (состояние `var:<имя>`): терминал (движок 31) шлёт свои изменения и берёт чужие; телефоны — `{{имя}}` в текстах блоков, ответах кодов, уведомлениях; коды телефона — действие «Переменная терминала» (записать или **прибавить**); правила центра — условие «общая переменная»; пульт мастера — «ОБЩИЕ ПЕРЕМЕННЫЕ». Загрузка пакета: переменные `shared` отмечаются в StoryInit (новые добавляются, значение — из пакета); отличия — раздел «Общие переменные» (по имени).
- **Окно «События»** (Т4-4 А, вкладка «История»): «Условие на терминале» — пассажи `sg-event` (условие, повтор, задержка, важность, **«Не переходить на экран»** — слово `stay`, **действия при срабатывании** — строка `<<sg-event-do>>…<</sg-event-do>>` сразу после первой); выполняет терминал. «Условие на телефонах» — правила центра (`<<app-rule>>` пассажа «Приложение»: событие, глава + N минут, каждые N минут, **общая переменная** `{on:'var', var, op, value}`); выполняет центр. В окне «Приложение» → «Сеть и события» → «Правила» — только список; его «Сохранить» правила не трогает. Форма события в пассаже — та же (со `stay` и действиями).
- **«Опубликовать пакет»** (Т4-2 А) — вместо «Собрать пакет»: проверка истории (раздел «Приложение для телефонов» и «Телефонам: нет в приложении»); ошибки — список и «Собрать всё равно»; иначе — пакет, предупреждения в сообщении.
- Проверки: `signaly-session35.test.ts`, `signaly/tests/electron-app-t4.mjs`, `net-play.mjs` (общая переменная с настоящим центром).

## Сессия 36 (решения 155–156; приложение — `app/05` П-67)
- **«Шапка и меню»** — вкладка окна «Приложение» (`signaly-app-header.tsx`, Т4-6 Б): в пакете `header` = `{title, sub, chapter, infoTitle, items: [{id, var, label, show: 'num'|'cells', max, unit, chapter, who}], info: [{id, title, text, chapter, who}]}` и `menu` = `[{tab, label, hidden}]` (`fullMenu`, `menuValue` в `signaly-app-model.ts`: без изменений — пустой список). Хранится, как всё верхнего уровня, в `<<app-general>>`. Предпросмотр телефона показывает шапку и меню сразу (плеер П14).
- **«Когда» у кода телефона** (Т4-5 А): в форме «На телефоне» — «Когда срабатывает (общие переменные)»: `when: [{var, op, value}]` и `whenText` в JSON `<<sg-phone>>`.
- **«Телефон сам ищет центр после входа»** (П-62) — «Общее» → «Связь», `chat.auto` (по умолчанию включено).
- **Отличия при загрузке пакета** (`diffDefaults` в `signaly-app.ts`): пустые `when`, `whenText`, `header`, `menu` от старого редактора — не отличия.
- **Проверка истории** (`signaly-app-check.ts`): условие «когда» и показатель шапки без общей переменной — ошибка; все вкладки меню скрыты — ошибка; `{{имя}}` в шапке и в ответе «нет доступа».
- **Событие «окно-сообщение»** (Т4-8 Б, движок 32): слово `popup` в `<<sg-event …>>` — терминал не переходит на экран, а показывает текст пассажа окном (`setup.signaly.openDialog({title: имя пассажа, passage})`), когда другое окно закрыто; действия `<<sg-event-do>>` — при показе. В окне «События» — 💬.
- Проверки: `signaly-session36.test.ts`, `signaly/tests/electron-app-t5.mjs`, `events-play.mjs` (+4: окно ждёт чужое окно, текст и заголовок, действия один раз).

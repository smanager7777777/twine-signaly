# Памятка автору — как собрать экран в «Twine СИГНАЛЫ»

> Сессия 25, ответ 5А; дополнена в сессиях 26 (музыка), 27 (радио, «Каталог Атмосферы»), 28 (эфир, вложенные папки), 29 (цвета радио, лампочка, реверс) и 30 (помехи по радио, радио с декодером, «СЛУЧАЙНО»). Коротко: что где лежит и как сделать частые вещи. Всё, что делают окна и формы, — обычный текст истории; история работает и в обычном Twine.

## 1. Где что лежит

**Вкладка «История» (верхняя панель)** — то, что общее для всей игры:

| Кнопка | Что там |
|---|---|
| Оформление терминала | Цвета, шрифт, рамка, мерцание, шум, стартовый экран, окна-сообщения, поля ввода, подсказки, «Назад» у статей. Вкладки «Виды экранов» (красный экран, без рамки…), «Стили текста», «Первое посещение» |
| Виды кнопок и ссылок | Янтарный, красный, фиолетовый… — цвета, наведение, нажатие, звуки |
| Звуки | Файлы, группы, плейлисты; наборы звуков наведения и нажатия |
| Переменные | Все переменные игры: имя, подпись, начальное значение, где используются |
| Горячие клавиши | Клавиши мастера: Shift+Z+буква → действия |
| Коды | Все пароли игры, сотрудники и их личные коды, тексты ошибок |
| Строка событий | Бегущая строка и «Цикл» на главном экране (цифры — DSEG7, «Шрифт цифр» на вкладке «Цикл») |
| **Музыка** | Каталог музыки: разделы «Атмосфера», «Радио», «Эфир» и **«Помехи»** (папка на каждое радио с эфиром), папки и вложенные папки, треки, громкость файла, условие, предзвук (игла), начальная громкость; передачи эфира; громкость в начале игры, «АВТО». «Сохранить» ещё разворачивает треки для реверса и достаёт картинки SSTV для радио с декодером |
| **Радио** | Виды радио по порядку игры (▲ Выше, ▼ Ниже): тип (сломанное С2, отремонтированное Р2 с эфиром, с реверсом В2, **с декодером Д2**), цвет каркаса и элементов, свои цвета кнопок, выключателя, шкалы, **лампочки**, каталога, **окна декодера**, внутреннего каркаса, надпись, искры; у радио с эфиром — белый шум, сколько помех выпадает, сообщение о передаче, время поимки; справа предпросмотр — само радио |
| **Проверить историю** | Перед игрой: ссылки в никуда, пропавшие файлы, переменные без значения, пустые коды, **треки радио без развёрнутой копии** (кнопка «Сделать копии») |

**Панель над текстом экрана** (открыть экран двойным щелчком на карте) — то, что относится к одному экрану:

| Кнопка | Что делает |
|---|---|
| Ж К Ч … цвет, размер | Форматирование выделенного текста |
| Вид | Вид ссылки или кнопки; «Сделать кнопкой / ссылкой» |
| Стиль текста | Готовый стиль выделенному тексту |
| Эффект | Печать, появление, смена, мигание, глитч, раскрытие по щелчку |
| Действие | Что делает ссылка: переменная, звук, окно, таймер, переход… |
| Условие | Показать текст, только когда выполнено условие |
| Событие | Этот экран откроется сам, когда условие станет верным |
| Доступ | Экран закрыт, пока не выполнено условие |
| Статья | Экран — статья для «Списка статей» |
| Подсказка | Текст, который всплывает при наведении |
| **Музыка экрана** | Через N секунд после входа на экран сменить музыку (затухание, что включить) |
| Добавить блок | Картинка, видео, поле кода, таймер, тревога, кнопка на экране, KR2, списки, взлом, камера, перебор (надписями или картинками), вставить экран, громкость, **радио**, **каталог Атмосферы** |
| Вид экрана | Красный экран, без рамки и т. п. (заготовки — в «Оформлении») |
| Первое посещение | Как экран возникает при первом заходе |
| Предпросмотр | Экран справа, вживую; элементы можно двигать мышью |

**Главное правило:** щелчок по команде в тексте открывает её форму под панелью. Править руками не нужно.

## 2. Собрать экран — по шагам

1. На карте: «Параграф» → «Новый». Переименовать (кнопка «Переименовать»): имя экрана — то, что будет в ссылках.
2. Написать текст. Ссылку на другой экран — `[[Надпись|Экран]]` или выделить слово → «Действие».
3. Выделить слово-ссылку → «Вид» → нужный цвет. Нужна кнопка — «Вид» → «Сделать кнопкой».
4. Нужно что-то сделать при нажатии — курсор на ссылку → «Действие» → «Добавить действие».
5. Картинка, видео, поле пароля — «Добавить блок». Двигать — мышью в «Предпросмотре» (снять «Закрепить»).
6. Красный или полноэкранный экран — «Вид экрана».
7. Проверить: «Предпросмотр» или «Тестировать» на вкладке «Сборка».

## 3. Частые задачи

**Кнопка меняет переменную и ведёт на экран.** Курсор на ссылку → «Действие» → «Изменить переменную» → выбрать, «задать 1» → внизу «После действий перейти на экран».

**Архив (состояние игры на экране).** «Добавить блок» → «Значение переменной»: «Глава: 3 из 5». Значение меняется само, без перехода. Строку, которая видна только при условии, — выделить → «Условие».

**Закрытый экран.** Открыть экран → «Доступ» → «Экран открыт, когда…» → выбрать пассаж блокировки («Ещё слишком рано»). Ниже — что делать каждой ссылке и паролю, если рано.

**Пароль.** Все пароли — окно «Коды» → «Добавить код»: код, что делает, ответ на экране. Поле ввода на экране — «Добавить блок» → «Поле кода», галочка «Проверять по общей таблице кодов». Только цифры — галочка «Только цифры» (ДЕШИФРАТОР).

**Окно-сообщение по кнопке.** Выделить надпись → «Действие» → «Открыть окно». (Старый блок «Окно-сообщение» открывается этой же формой.)

**Статусы KR2.** Строки справа внизу — обычный текст между `<<kr2vars>>` и `<</kr2vars>>`: «Условие», «Значение переменной», ссылка с «Открыть окно». В форме KR2 — только картинка и доли зон.

**Музыка.** «Музыка» на вкладке «История» → «Добавить папку» → «Добавить трек» (файл, условие, предзвук). Кнопки на экране — «Действие» → «Музыка»: «Включить или поставить на паузу раздел» (как РАД и АТМ), «Пауза», «Продолжить», «Стоп», «Следующий трек», «Громкость: поставить» (A–E: 10, 20, 30, 50, 99), «АВТО». Окошко громкости — «Добавить блок» → «Громкость». Смена музыки при входе на экран — кнопка «Музыка экрана».

**Радио.** «Радио» на вкладке «История» → вид (цвета, искры). На экране — «Добавить блок» → «Радио» → выбрать вид. В каталоге радио — папки раздела «Радио» окна «Музыка». Выключатель на радио возвращает на экран, откуда пришли. У всех радио есть «АВТО», «СЛУЧАЙНО» (следующий трек — случайный) и полоса прогресса (перемотка).

**Эфир (отремонтированное радио).** «Радио» → вид типа «Отремонтированное»: файл белого шума и где он звучит, сколько помех выпадает за раз. Передачи — «Музыка» → раздел «Эфир» → трек: файл, условие (когда появляется в эфире), «После поимки — в папку радио», ширина слышимости, своё сообщение. Игроки жмут «ПОИСК», тянут иглу, донастраивают −/+ и держат точную настройку — передача попадает в каталог. Передача без папки — помеха эфира: звучит, но не ловится.

**Помехи.** «Музыка» → раздел «Помехи»: папка на каждое радио с эфиром, в порядке окна «Радио» (папки появляются сами). Трек помехи — как обычный трек, плюс «Слышно в пределах ±». При входе на экран радио на шкалу выпадает одна уже пойманная помеха этого радио и ещё не пойманные этого радио и радио выше в списке. Помеху можно поймать, как передачу: она попадёт в каталог радио, папку «Помехи». Порядок радио — ▲ Выше / ▼ Ниже в окне «Радио».

**Лампочка на шкале.** Встали на передачу или помеху кнопками −/+ точно — загорается круг в правом верхнем углу шкалы. Иглой — не загорается: иглой ищут грубо, кнопками — точно. Свой цвет — «Радио» → «Лампочка точной настройки».

**Цвета радио.** «Радио» → вид → «Кнопки», «Выключатель (выход)», «Шкала поиска, частота, прогресс», «Лампочка точной настройки», «Каталог», «Окно декодера и ДЕКОД», «Внутренний каркас». Пусто — как у «Элементов» (лампочка — как у шкалы, внутренний — как у «Каркаса»).

**Реверс.** «Радио» → вид типа «С реверсом» (или «С декодером») → «Сохранить»: программа сама развернёт треки раздела «Радио», передачи и помехи в папку игры `media/audio/reverse` (в шапке окна — «Развёрнуто N копий»). Добавили трек в «Музыке» — «Сохранить» там развернёт и его. Своё послание задом наперёд — «Музыка» → трек → «Файл задом наперёд». В игре: зажать РЕВЕРС мышью — трек задом наперёд, отпустить — дальше вперёд. **Переносите игру на другой компьютер вместе с папкой `media/audio/reverse`** (нет копии — строка радио пишет «◀◀ РЕВЕРС НЕДОСТУПЕН»; «Проверить историю» → «Сделать копии»).

**Радио с декодером (картинки SSTV).** «Радио» → вид типа «С декодером, каркас Д2». Картинку кладут в звук программой SSTV (MMSSTV и подобные; режимы Robot 36/72, Martin 1/2, Scottie 1/2/DX, PD 50…290). Звук — в «Музыке» как помеха или передача эфира → «Сохранить»: программа найдёт картинки (в шапке — «Картинок SSTV: N») и положит их в `media/img/sstv`. В игре: «ДЕКОД» → найти звук с картинкой — в окне слева набирается картинка в такт звуку; щелчок по окну — на весь терминал. **Переносите игру вместе с папкой `media/img/sstv`.**

**Папки внутри папок.** «Музыка» → выбрать папку → «Вложенная папка». В радио игроки заходят в папку и выходят «◄ ..». Громкий файл — «Громкость файла» у трека меньше 100 %.

**Атмосфера.** «Добавить блок» → «Каталог Атмосферы»: альбомы — папки раздела «Атмосфера», подсказка альбома — в окне «Музыка». Игроки видят «Прослушано: 2 из 5», могут включить «Случайно» и сбросить прогресс. Кнопка «Включить Атмосферу» на экране — «Действие» → «Музыка» → «Включить раздел».

**Сообщение мастера клавишей.** «Горячие клавиши» → «Добавить» → «Задать нажатием» → действие «Открыть окно» → текст. Звук поверх музыки — действие «Звук-сигнал», галочка «Приглушить на время файла» → «Музыка и радио».

**Событие (терминал сам переходит на экран).** Открыть экран события → «Событие» → условие. Один раз или «Повторять».

**Кусок, общий для многих экранов** (кнопки звука, шапка). Сделать отдельный экран с этим куском. На других экранах — «Добавить блок» → «Вставить экран» → выбрать. Правите кусок в одном месте — меняется везде.

**Процедуры и системы.** «Добавить блок» → «Список состояний: кнопки» или «плитка». «Добавить много строк» — сразу 99 строк по образцу.

## 4. Перед игрой

1. «Проверить историю» — список пуст или в нём только то, что вы знаете.
2. «Сборка» → «Опубликовать в папку игры».
3. Пройти список проверки на ноутбуке (`claude/09_REHEARSAL_CHECKLIST.md`).

## 5. Если что-то пошло не так

- **Экран пустой или красная надпись «Ошибка»** — открыть экран, щёлкнуть по команде рядом с ошибкой: форма покажет, что не так. Или «Проверить историю».
- **Нет звука или картинки** — «Проверить историю», раздел «Файла нет в папке игры». Имя файла должно совпадать до буквы.
- **Игра после сбоя** — откройте ту же игру: терминал продолжит с того же места. Музыку и декодер включает мастер.
- **Начать заново** — Shift+Z+N → «Да».
